# Introduction de l'atelier

```bash
npm install
npm run dev      # présentation sur http://localhost:3030
npm run build    # site statique dans dist/
```

- Publication sur GitHub Pages : `npm run build -- --base /NOM-DU-REPO/`, puis déployer le dossier `dist/`.
- Export PDF : `npm i -D playwright-chromium` puis `npm run export`.
